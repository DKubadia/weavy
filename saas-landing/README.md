# Nexora — SaaS Landing Hero

A self-contained SaaS landing page hero section built with **Vite + React 18 + TypeScript + Tailwind CSS**.

The Navbar + Hero fill exactly `100vh` with no scroll. The hero features a fullscreen
background video, animated content (framer-motion), and a fully hand-coded dashboard
preview (no images) with an SVG area chart.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS + `tailwindcss-animate`
- `framer-motion` for entrance animations
- `lucide-react` for icons
- shadcn/ui-style `Button` component
- Google Fonts: Instrument Serif (display) + Inter (body)

## Getting started

```bash
cd saas-landing
npm install
npm run dev
```

Then open the printed local URL.

## Build

```bash
npm run build
npm run preview
```
